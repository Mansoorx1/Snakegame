# Pond Snake

A small browser game: steer the snake, eat the koi, don't hit the edge or yourself.

## Play locally

Open `index.html` in any browser. No build step or dependencies.

## Controls

- Arrow keys or WASD to steer
- Space to pause
- Swipe on a phone

## Publish on GitHub Pages

1. Push these files to a GitHub repo.
2. In the repo, go to Settings, then Pages.
3. Under Branch, choose `main` and `/ (root)`, then save.
4. Your game will be live at `https://<your-username>.github.io/<repo-name>/`.
